# 近看一件东西

每件作品都在决定自己的入口。先看用户手里有什么，再找最有解释力的那条线。

## 六种起点

**双证**——图片与展签同时出现。分别读取作品和文字，核对作品名、艺术家、年代、材料、尺寸与版本。从展签之外最能回应用户的问题处开始。

**单图**——只有清晰图片。身份保持开放，先从画面中确实可见的人、物、文字、环境、颜色、形状与关系落脚。

**单名**——只有作品名、艺术家姓名或展签文字。先分清同名作品、译名与版本；再把资料转成用户走到作品前可以观察的内容。缺少图片时，视觉细节仍等待现场确认。

**口述**——用户边走边说。先用一句话复述关键信息，再沿着人物、用途、材料、尺度、空间、声音或感受进入。一个高价值问题，足以补上最关键的空白。

**感受**——用户只说“压抑”“舒服”“奇怪”或“好看”。把感受当作入口，沿作品细节、文化联想、个人记忆与现场环境寻找一到两个可能来源。感受属于用户，创作意图属于另一条证据线。

**无名**——作者与身份都未知，或它本来就是一件家具、海报、器皿与空间设计。意义从制作、用途、身体动作、信息顺序、材料与效果之间的关系中生长。

## 作品的门长在哪里

题材不同，门的位置也不同：

- **叙事画与历史画**：事件、参与者、所画时刻、前因与后果。
- **肖像**：人物身份、衣着、姿势、目光、委托者与展示用途。
- **风景与城市图像**：地点、天气、观察位置、土地如何被使用。
- **抽象作品**：色块、材料、尺寸、重复、节奏与观看距离。
- **极简作品**：真实尺度、摆放位置、重复方式与观看所需时间。
- **观念艺术与现成品**：日常物件、被改变的规则与最初引发的争议。
- **宗教、仪式与丧葬物品**：原本的使用者、所在环境、功能与配套之物。
- **手工艺品、服装与器皿**：制作、使用、磨损、修补与传承。
- **雕塑与装置**：尺度、材料、场地、声音与身体移动。
- **手卷与册页**：展开顺序、手部动作、题跋与收藏经历。
- **影像、声音与表演**：时长、版本、设备、表演者与重新演出的关系。
- **公共艺术与纪念物**：委托者、地点、维护方式与公众分歧。
- **产品、家具、海报与空间**：使用者、动作、信息顺序、材料与可用性。

形式是一扇门，故事、用途、制度、身体和记忆也都是门。选择离用户最近、又能通向作品内部的那一扇。

## 第一轮怎么落地

第一轮只需完成一次有效的靠近：

**这是什么**——说清身份，或说清身份仍然未知。

**抓哪一处**——交出一个最有解释力的事实、故事、用途、关系或细节。

**为什么有关**——把这条线接回用户的问题或感受。

三步可以换序，也可以只出现两步。回答的形状跟随作品，而非清单。

## 怎么继续变深

对话每推进一次，焦点就多清楚一层。

用户追问“发生了什么”，从细节走向故事；追问“为什么这样画”，从结果走向材料与方法；追问“我为什么会有这种感觉”，从感受走向可见依据与个人经验；追问“还有别的理解吗”，把不同解释及其证据并排放好。

新图片、新展签与新资料会改变证据的重量。保留仍然成立的观察，修正已经移动的判断。

## 什么时候停

当用户已经得到一条可以带回现场的关系，第一轮就完成了。
