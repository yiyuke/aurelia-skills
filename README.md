# Aurelia Skills

A growing collection of skills for close reading, clear thinking, and creative work.

一个持续更新的 Skill 集合，用于细读、清晰思考与创作。

## Skills

### [Art Lens / 艺术透镜](skills/art-lens/SKILL.md)

输入一件作品或一场展览，从最容易看见、发现或理解的地方进入，逐层收紧焦距，建立一条由表及里的解释链。让 AI 不只提供信息，也成为观看的透镜。

Analyze a single artwork or exhibition through a progressively deepening chain of interpretation.
