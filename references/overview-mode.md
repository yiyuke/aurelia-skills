# 远看一场展览

进场前的概览是一张认知地图。它让用户知道自己将走进什么、各部分为何相连、有限时间先看哪里。

## 地图从哪里长出来

先确认名称、场馆、城市、日期与展览版本，再画地图。

资料来源：

1. 美术馆、主办方与展览官方页面；
2. 官方手册、新闻稿、图录与策展人说明；
3. 艺术家遗产管理机构、档案馆与基金会；
4. 可靠的学术研究；
5. 评论文章，用来理解社会反响与不同意见。

主办方的主题是一项可引用的事实；把它重新讲清楚，是解释者的工作。两者各自署名。可以联网时，为主要资料留下可直接打开的链接。

## 一页的骨架

一页导览回答五件事：

**先说结论**——这是什么展，它主要沿着哪条线组织。

**这个人／这群人**——选择三到五项真正能解释本次展览的经历，让生平与展出的时期、地点、题材、材料、合作或工作方法发生联系。

**展览主线**——说明两到四个官方章节怎样前后衔接。官方没有划分章节时，把自拟结构明确写成便于理解的归纳。

**进去抓什么**——给出一到三件值得记住的作品、变化、比较关系或问题。

**依据来自哪里**——简要列出主要官方或学术资料。

把它收在 350—600 个汉字里，约 60—90 秒读完。短标题和项目符号让用户在手机上扫一眼就能找到位置。

## 生平留下什么

生平不是年表，而是展览的因果线。

一项经历进入概览，是因为它能解释眼前的一段创作：一次迁居带来题材变化，一种合作改变制作方式，一项委托决定作品用途，一个历史处境影响材料选择。

苦难、疾病、天才与反叛也属于需要证据的解释。它们与具体作品发生可说明的联系时，才拥有位置。

## 长墙怎样变短

展墙文字常把事实、策展判断和宣传语言叠在一起。压缩时逐层分开：

**留骨头**——保留人物、时间、事件、顺序和主办方真正想建立的联系。

**落到眼前**——把抽象概念译成观众实际会看到、比较或进行的动作。

**守住空白**——照片中看不清的字保持未识别；外部资料只在用户要求查证，或缺失会造成误解时进入。

压缩完成后，用户应能说出主线，同时仍愿意走进去亲自看。

## 路线从哪里来

认知顺序来自内容，实际路线来自地图。

美术馆官网、应用程序、官方手册、PDF、入口导向照片或用户上传的平面图，可以支持楼层、展厅与转弯方向。可靠地图缺席时，给出主题先后和内容优先级。

时间有限，就把选择与代价一起说清：优先哪一章会得到什么，略过哪一章会失去什么。

## 进场之后

用户上传一件作品，视线便从地图落到现场。切换到“近看一件东西”，先用一两句话接回它所在的展览主线，再回应眼前的新问题。

地图在这里完成使命，作品开始说话。
